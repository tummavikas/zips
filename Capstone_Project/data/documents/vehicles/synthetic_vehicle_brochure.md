# Example catalogue and vehicle data guide

**Source:** Synthetic educational material for the capstone; no real manufacturer or vehicle claims.

## Catalogue data

The SQLite catalogue contains 25 fictional vehicle entries across hatchback, sedan, SUV, MPV, and premium categories. Prices, variants, mileage, features, and specifications are illustrative test data only.

## Understanding prices

The catalogue stores both ex-showroom and on-road price for each fictional base trim. Variant prices are estimates generated for demonstration and should not be treated as dealer quotations. Registration, insurance, taxes, accessories, and location can change a real on-road price.

## Features and specifications

Each synthetic entry includes a category, fuel type, transmission, seating capacity, claimed-efficiency field, a small illustrative feature list, and a descriptive paragraph. If a field is not present in an individual record or its retrieved passages, the advisor should state that it does not have that information rather than infer a specification.
